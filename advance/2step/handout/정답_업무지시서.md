# 업무지시서 — 직영 최근월 과목수 · 학생수 리포트

너는 이 업무를 혼자 처음부터 끝까지 해낸다. 사람은 옆에 없다. 질문하지 말고, 이 문서만 보고 진행한다.

## 목표
직영 리포트 담당(jig-report) 에이전트에게 맡겨 `직영_실습데이터.csv` 에서 **가장 최근 편성년월**의 과목수 · 학생수 리포트(HTML)를 만들게 한다.

## 작업 위치
- 프로젝트 폴더: 이 파일이 있는 `ai_staff` 의 상위 폴더(basic_data). 모든 경로는 이 폴더 기준이다.
- 원본 데이터: `./직영_실습데이터.csv` (열 설명은 `./열사전.txt`)
- 리포트 저장: `./리포트/`
- 계산용 임시 파일(.js, 중간 결과 등): `./ai_staff/작업/` **에만** 둔다. 다른 곳에 임시 파일을 만들지 않는다.

## 순서
1. **오늘 날짜 구하기** — `node -e` 로 오늘 날짜를 YYYYMMDD 형식으로 구한다(로컬 시간 기준).
2. **파일 이름 정하기** — 기본 이름은 `리포트/자동_YYYYMMDD.html`.
   - Glob 으로 `리포트/자동_YYYYMMDD*.html` 이 이미 있는지 본다.
   - 없으면 기본 이름, 있으면 `자동_YYYYMMDD_v2.html`, 그것도 있으면 `_v3` … 처럼 아직 없는 첫 이름을 쓴다.
   - 기존 파일은 절대 덮어쓰지 않는다.
3. **jig-report 에이전트에게 맡기기** — Agent 도구로 `subagent_type: jig-report` 를 부르고, 아래 내용을 그대로 전달한다(파일 이름은 2번에서 정한 것으로 바꿔 넣는다).

   ```
   직영_실습데이터.csv 로 가장 최근 편성년월의 과목수 · 학생수 리포트를 만들어 줘.
   - 대상 달: 데이터에서 가장 최근 편성년월 하나. 리포트 제목과 요약에 그 달(YYYYMM)을 적는다.
   - 세는 법: jig-metrics 기준(제외 프로그램 · 휴회 · 반이동 제외, 학생수는 센터별로 센 뒤 합산, 학년치환 적용).
   - 저장 파일: ./리포트/<정한 파일 이름>  — 이미 있으면 _v2, _v3 를 붙여 아직 없는 이름으로 저장하고, 덮어쓰지 않는다.
   - 계산용 .js 나 중간 파일은 ./ai_staff/작업/ 에만 만든다. 다른 곳에 만들지 않는다.
   - Node 로만 계산한다(Python 금지). 원본 CSV 는 고치지 않는다. .env 등 데이터와 관계없는 파일은 열지 않는다.
   - 보고는 결론 3줄 + 저장한 파일 이름만. 막히면 「확인 필요: 이유」 한 줄로 보고한다.
   ```
4. **결과 확인** — 에이전트 보고를 받은 뒤:
   - Glob 으로 보고된 파일이 `리포트/` 안에 실제로 있는지 확인한다.
   - Read 로 파일 앞부분을 열어 제목 · 대상 달 · 과목수 · 학생수가 들어 있는지 본다.
   - 보고된 숫자와 파일 안의 숫자가 다르거나 파일이 없으면 「확인 필요: 이유」 로 끝낸다.
5. **검산 맡기기** — 리포트 담당과 다른 에이전트 하나를 검산 담당으로 따로 부른다. 검산 담당용 에이전트 파일은 새로 만들지 않고, Agent 도구로 `subagent_type: general-purpose` 를 부른다. 아래 내용을 그대로 전달한다(파일 이름은 4번에서 확인한 것으로 바꿔 넣는다).

   ```
   너는 검산 담당이다. ./리포트/<확인한 파일 이름> 의 과목수 · 학생수가 맞는지 검산해 줘.
   - 먼저 Skill 도구로 jig-metrics 스킬을 불러 그 세는 법을 따른다(제외 프로그램 · 휴회 · 반이동 제외, 학생수는 센터별로 센 뒤 합산, 학년치환 적용).
   - 리포트에 적힌 과목수 · 학생수(요약 · 월별 표 · 학년별 표)를 직영_실습데이터.csv 에서 처음부터 다시 세어 하나씩 대조한다. 리포트 안의 계산 결과나 리포트 담당이 만든 중간 파일은 쓰지 않는다.
   - 리포트 파일은 고치지 않는다. 원본 CSV 도 고치지 않는다.
   - 계산용 .js 나 중간 파일은 ./ai_staff/작업/ 에만 만든다. Node 로만 계산한다(Python 금지).
   - 보고는 아래 둘 중 하나만:
     · 모두 같으면: 「일치」 한 줄
     · 다르면: 다른 숫자마다 한 줄 — 「항목: 리포트 값 → 다시 센 값 (다른 이유)」
   ```
6. **다르면 고치게 하기** — 검산 담당이 「일치」 가 아닌 결과를 돌려주면:
   - 2번 규칙대로 아직 없는 새 파일 이름(`_v2`, `_v3` …)을 정한다. 틀린 리포트는 지우거나 덮어쓰지 않는다.
   - jig-report 에이전트를 다시 불러 3번의 전달 내용에 아래 줄을 덧붙여 보낸다(새 파일 이름으로 바꿔 넣는다).
     ```
     - 앞서 만든 ./리포트/<틀린 파일 이름> 에서 검산 결과 다른 숫자가 나왔다. 아래 내용을 확인해 고친 리포트를 새 파일로 만들어 줘.
       (검산 담당이 돌려준 줄을 그대로 붙인다)
     ```
   - 새 리포트도 4번(결과 확인) · 5번(검산)을 한 번 더 거친다.
   - 두 번째 검산에서도 다르면 더 고치지 않고 `확인 필요: 검산 후 고친 리포트도 숫자가 다름 — (다른 항목)` 한 줄로 끝낸다.
7. **마지막 답 쓰기** — 아래 형식만 쓴다.

## 마지막 답 형식
결론 3줄 + 파일 이름 + 검산 한 줄. 그 밖의 설명 · 인사 · 과정 설명은 붙이지 않는다. 결론과 파일 이름은 마지막으로 검산을 통과한 리포트 기준으로 쓴다.

```
1. (가장 최근 편성년월과 과목수)
2. (학생수)
3. (눈에 띄는 점 한 가지 — 예: 학년별 최다 구간)
리포트/자동_YYYYMMDD.html
검산: 일치
```

- 처음 리포트가 검산에서 맞았으면 마지막 줄은 `검산: 일치`
- 고친 리포트를 다시 만들었으면 `검산: 고침 — 무엇` (예: `검산: 고침 — 202609 학생수 1,234 → 1,230`)

## 막혔을 때
- 사람에게 질문하지 않는다.
- 진행할 수 없으면 다른 말 없이 한 줄로 끝낸다: `확인 필요: 이유`
  - 예: `확인 필요: 직영_실습데이터.csv 가 없음`
  - 예: `확인 필요: 리포트 폴더에 쓰기 권한 없음`
  - 예: `확인 필요: jig-report 보고 숫자와 리포트 파일 숫자가 다름`

## 하지 않는 것
- 원본 CSV · 열사전 · `.claude` 설정 · `.env` 를 고치거나 열지 않는다(데이터 파일 읽기는 jig-report 가 Node 로 한다).
- `리포트/` 와 `ai_staff/작업/` 밖에 파일을 쓰지 않는다.
- 이미 있는 리포트를 덮어쓰거나 지우지 않는다(검산에서 틀린 리포트도 그대로 둔다).
- 검산 담당용 에이전트 파일을 새로 만들지 않는다. 검산 담당은 리포트를 고치지 않는다.
- 데이터에 없는 숫자를 지어내지 않는다.
