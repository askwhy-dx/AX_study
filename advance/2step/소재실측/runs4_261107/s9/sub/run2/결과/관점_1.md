# 관점 1 · 규정 담당 — 항의편지 요청 · 불만별 해당 조항

기준: 편지 받은 날 2026-11-08 · 응대규정 2026년 11월 판(현행)

## 1. 도윤(초4) 이번 달로 그만둠 · 11월 수강료 환불
- 해당 조항: 1. 수강료 환불
- 사실: 11월 수업 8회 중 2회 들음 → 수업 시작 뒤
- 계산: 1/3 지점 = 8 × 1/3 ≈ 2.67회 · 1/2 지점 = 4회. 지난 수업 2회 < 2.67회 → 「1/3 이 지나기 전」
- 결론: 11월 수강료의 **2/3 환불**
- 금액: 편지 · 규정에 월 수강료 금액이 없어 원 단위로는 못 적는다(수강료 × 2/3). 확인 후 안내.
- 주의: 다음 수업을 더 들어 3회째가 지나면 1/3 을 넘어(3/8 = 0.375) 1/2 환불로 줄고, 5회째부터(4회 초과)는 환불 없음 → 빨리 처리할수록 유리

## 2. 11월 3일 받은 4학년 교재 2권
- 해당 조항: 3. 교재비 환불
- 계산: 받은 날 11-03 → 편지 11-08 = 5일째 → 「받은 날부터 7일 안」 충족(7일 기한 = 11-10 무렵 · 늦어도 11-09 까지 신청하면 안전)
- 뜯어서 풀기 시작한 1권: 포장 뜯음 → **환불 없음**
- 비닐 안 뜯은 1권: 7일 안 + 미개봉 → **교재비 환불**
- 금액: 권당 교재비는 규정에 없음(12조의 「교재비 월 2만 원」은 휴원 관련 월 금액이라 권당 가격으로 쓰지 않는다) → 확인 후 안내

## 3. 서윤(초2) 형제 할인 계속 받는지
- 해당 조항: 11. 형제 할인
- 조건: 형제가 **같은 달에 함께** 수업을 들으면 동생 수강료 **10% 할인**
- 11월: 둘 다 다님 → 서윤 10% 할인 해당
- 12월부터: 도윤이 그만두면 같은 달에 함께 듣지 않음 → **할인 없음**(계속 받는다고 답하면 안 됨)

## 4. 차량 지연(이번 달 2번 · 20분 넘게) 불만
- 지연 보상 · 사과 기준: **규정 없음** → 보상 약속 금지(9조), 「확인 후 다시 연락드리겠습니다」

## 5. 집 앞 정류장 5분 일찍 와 달라
- 해당 조항: 6. 차량
- 시간 · 정류장 변경은 담당 선생님이 운행표 확인 뒤 따로 연락 · **상담 답변에서 확정하지 않는다**

## 6. 옆집 하준이 단원평가 점수
- 해당 조항: 7. 개인정보
- 다른 학생 성적은 **어떤 경우에도 알려주지 않는다**

## 7. 도윤 성적이 떨어진 이유
- 해당 조항: 8. 성적 · 수업 내용 문의
- 담당 선생님 상담으로 연결 · 답변에서 성적 평가 금지

## 8. 12월 한 달 무료로 해 주면 계속 보내겠다
- 무료 수업 · 특별 혜택: **규정 없음**
- 해당 조항: 9. 답변 말투 — 규정에 없는 할인 · 예외 · 특별 혜택은 약속하지 않고 「확인 후 다시 연락드리겠습니다」

## 9. 답장 형식(9조)
- 첫 줄 「안녕하세요, 가상 수학교실입니다.」
- 5줄 안

## 참고 (편지에 직접 요청은 없음)
- 그만두는 대신 쉬게 하려면 5조 휴원: 한 번에 최대 2개월 · 휴원 시작 7일 전까지 신청 · 휴원 기간 수강료 없음. 단 휴원한 달은 형제 할인 없음(11조 2항).
- 결석 보강(2조)은 편지에서 요청하지 않음 — 해당 없음.
