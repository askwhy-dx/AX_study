이 폴더의 과제.md 대로 겨울특강 안내 포스터를 만든다.
에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 3명(designer · copy · parent, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. designer = 화면 배치 · 색 · 글자 크기를 맡고 답변\포스터.html 을 직접 쓴다 · copy = 문구 · 숫자 · 날짜가 원문 · 규정과 맞는지 맡는다 · parent = 처음 보는 학부모 눈으로 5초 안에 알아보는지 맡는다. 각 팀원 프롬프트에: 이 폴더 절대경로 · 과제.md · 「파일은 Write · Edit 도구로만 쓴다.」 · 다른 두 팀원의 이름과 역할 · 「SendMessage 로 서로 의견을 주고받는다: copy · parent 는 고칠 점을 designer 에게 보내고, designer 는 반영하거나 이유를 들어 답한다 · 의견이 다르면 셋이 정한다」 · 「copy 는 고친 점을 답변\고친점.md 에 쓴다」 · 「끝나면 SendMessage 로 main 에게 '완료' 를 보낸다」. 세 명의 완료 메시지를 받으면 너는 포스터.html 이 있는지만 확인한다(내용을 고치지 않는다). 끝나면 「완료 · 포스터.html」 한 줄만 보고한다.
