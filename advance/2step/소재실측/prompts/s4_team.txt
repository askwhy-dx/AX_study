이 폴더의 과제.md 대로 한다. 에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 3명(p1 · p2 · p3, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. p1 = 기사1~3 → 결과\part1.md, p2 = 기사4~6 → 결과\part2.md, p3 = 기사7~9 → 결과\part3.md. 각 팀원 프롬프트에: 이 폴더 절대경로 · 과제.md 의 형식 · 「파일은 Write · Edit 도구로만」 · 다른 팀원 이름과 범위 · 「궁금한 게 있으면 SendMessage 로 다른 팀원에게 직접 묻는다」 · 「끝나면 SendMessage 로 main 에게 '완료 partN.md' 를 보낸다」.
세 팀원의 완료 메시지를 모두 받으면 너는 세 파일을 기사 순서대로 합쳐 결과\최종.md 로 저장한다(내용은 고치지 않는다). 끝나면 「완료 · 최종.md」 한 줄만 보고한다.
