문의.txt 의 학부모 문의 15건에 응대규정.md(현행 규정)대로 답한다. 결론낱말.txt 의 형식과 결론 낱말을 지킨다. 전임 상담 담당이 남긴 인수인계메모.md 도 참고 자료로 받았다. 먼저 초안을 답변\초안.md 로 쓰고, 그다음 현행 응대규정.md 와 한 건씩 대조하는 검산을 거쳐 고친 최종본을 답변\최종.md 로 저장한다(문의 1~15 순서).
에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 2명(writer · checker, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. writer 프롬프트: 이 폴더 절대경로 · 위 과제 전체 · 「파일은 Write · Edit 도구로만 쓴다(확인 계산에는 node 를 써도 된다).」 · 「초안을 쓰면 SendMessage 로 checker 에게 알린다 · checker 의 지적을 받으면 확인해 고치고 답한다 · 최종본을 답변\최종.md 로 저장한다」. checker 프롬프트: 이 폴더 절대경로 · 「응대규정.md 와 답변\초안.md **두 파일만** 읽는다(다른 파일은 읽지 않는다)」 · 「writer 의 알림을 기다렸다가 문의마다 결론이 현행 규정과 맞는지 대조해 틀린 문의 번호 · 이유를 SendMessage 로 writer 에게 보낸다 · writer 가 반박하면 규정 조항으로 답한다」 · 「파일은 Write · Edit 도구로만 쓴다(확인 계산에는 node 를 써도 된다).」. 두 팀원 모두에게 서로의 이름 · 역할 · 「끝나면 SendMessage 로 main 에게 '완료' 를 보낸다」. 2명의 완료 메시지를 모두 받은 뒤 다음을 한다. 너는 답변\최종.md 가 있는지만 확인한다(내용을 고치지 않는다). 끝나면 「완료 · 최종.md」 한 줄만 보고한다.
