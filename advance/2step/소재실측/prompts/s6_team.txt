이 폴더의 과제.md 대로 통신문.md 를 검토한다. 에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 4명(calc · date · logic · rule, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. calc = ① 계산 → 결과\검토_1.md, date = ② 날짜와 요일 → 결과\검토_2.md, logic = ③ 앞뒤가 맞지 않는 내용 → 결과\검토_3.md, rule = ④ 규정 · ⑤ 개인정보 · ⑥ 맞춤법 → 결과\검토_4.md. 각 팀원 프롬프트에: 이 폴더 절대경로 · 과제.md 의 출력 형식 · 「자기 항목만 깊게 본다」 · 「파일은 Write · Edit 도구로만(확인 계산에는 node 를 써도 된다)」 · 다른 세 팀원의 이름과 항목 · 「읽다가 다른 팀원 항목의 오류로 보이는 것을 발견하면 SendMessage 로 그 팀원에게 줄 번호와 이유를 알려 준다 · 받은 제보는 직접 확인해 맞으면 자기 목록에 넣는다」 · 「끝나면 SendMessage 로 main 에게 '완료 검토_N.md' 를 보낸다」.
네 팀원의 완료 메시지를 모두 받으면 너는 네 파일을 합쳐 결과\오류목록.md 로 저장한다(같은 줄이 겹치면 하나로 · 새로 찾거나 빼지 않는다). 끝나면 「완료 · 오류목록.md」 한 줄만 보고한다.
