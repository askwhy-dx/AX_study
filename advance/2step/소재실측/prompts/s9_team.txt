에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 3명(rule · parent · ops, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. 관점: 규정 담당(조항마다 해당 사항과 정확한 수치) · 학부모 담당(학부모가 실제로 원하는 것 · 놓치기 쉬운 요청 · 마음) · 운영 담당(센터가 약속해도 되는 것과 안 되는 것 · 후속 연락) (rule=규정 · parent=학부모 · ops=운영). 각 팀원 프롬프트에: 이 폴더 절대경로 · 「파일은 Write · Edit 도구로만 쓴다(확인 계산에는 node 를 써도 된다).」 · 다른 두 팀원의 이름과 관점 · 「항의편지.txt · 응대규정.md 를 읽고 자기 관점 목록을 결과\관점_이름.md 에 쓴다」 · 「다른 팀원에게 SendMessage 로 상대 목록에서 빠졌거나 틀린 것을 알려 주고, 받으면 확인해 반영한다」 · 「rule 이 셋의 의견을 모아 답장 초안을 답변\최종.md 에 쓰고, parent · ops 가 읽고 고칠 점을 rule 에게 보내 rule 이 고친다」 · 「끝나면 SendMessage 로 main 에게 '완료' 를 보낸다」. 3명의 완료 메시지를 모두 받은 뒤 다음을 한다. 너는 답변\최종.md 가 있는지만 확인한다(내용을 고치지 않는다). 끝나면 「완료 · 최종.md」 한 줄만 보고한다.
