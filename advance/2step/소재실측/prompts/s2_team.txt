이 폴더의 문의.txt 60건에 응대규정.md 대로 답변을 쓴다. 결론낱말.txt 의 형식과 결론 낱말을 지킨다.
에이전트 팀으로 한다: Agent 도구에 name 을 붙여 팀원 3명(p1 · p2 · p3, general-purpose)을 한 메시지에서 동시에 백그라운드로 띄운다. p1 = 문의 1~20 → 답변\part1.md, p2 = 21~40 → 답변\part2.md, p3 = 41~60 → 답변\part3.md. 각 팀원 프롬프트에: 이 폴더 절대경로 · 형식 · 결론 낱말 · 「파일은 Write · Edit 도구로만」 · 다른 팀원 이름과 맡은 범위 · 「궁금한 게 있으면 SendMessage 로 다른 팀원에게 직접 묻는다」 · 「끝나면 SendMessage 로 main 에게 '완료 partN.md' 를 보낸다」.
세 팀원의 완료 메시지를 모두 받으면 너는 세 파일을 문의 순서대로 합쳐 답변\최종.md 로 저장한다(내용은 고치지 않는다). 끝나면 「완료 · 최종.md」 한 줄만 보고한다.
