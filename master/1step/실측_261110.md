## 4. 실측 방법 (다시 돌릴 때)

- 시험 폴더 = 임시 워크스페이스 `ws\`
  - `ws\.claude\agents\cs-reply.md` ← `advance/2step/handout/정답_응대담당.md`
  - `ws\cs_practice\` ← `advance/2step/handout/cs_practice` (문의.txt · 응대규정.md · 응대규정_옛판.md · 담당별\)
  - 정답표 = `advance/2step/handout/정답표_문의답변.txt` [1] (문의 4 보강 가능 · 9 교재비 환불 가능 · 13 다음 달 1일)
- 실행: `claude -p --permission-mode acceptEdits --allowedTools "Read,Write,Edit,Glob,Grep,Bash,PowerShell,Agent" < 프롬프트.txt`
  - 「exit → claude 로 새로 켜기」 = 새 프로세스 · 「이어서」 = `-c`
  - ⚠️ `--allowedTools` 는 뒤의 인자를 다 먹으므로 프롬프트는 **stdin** 으로 넘긴다(인자로 주면 「Input must be provided」 오류)
  - ⚠️ `--permission-mode bypassPermissions` 는 auto 모드 분류기가 거부함
  - ⚠️ `.claude` 아래 쓰기는 acceptEdits 로도 막힘 → 4 · 5단계 훅 만들기는 대화형만
- 순서: 1a · 1b · 2a · 2b · 2c(-c) · 3 → (원본 복원) → 정답 훅 넣기 + cs_practice git init → 4b · 4c(-c) · 4c2(새 세션) → 5b · 5c(-c) → 6 → `.git` 치움 → off1~3(cs_off) · on1~3 → 8a · 8b(-c)
  - 1·2단계 수정판은 별도 `ws2\` 에서 f1a · f1b · f2a · f2b · f2c(-c)
- Auto Memory 는 `~/.claude/projects/<시험 폴더 경로>/memory` 에 쌓인다 — 끝나면 그 폴더를 지운다(이번에 3개 지움)
- 원본 손상 확인: `md5sum 문의.txt 응대규정.md 응대규정_옛판.md` 를 시작 전 저장 → 단계마다 `md5sum -c`
