description: 문의 답변 → 검산 → 고침 → 슬랙 보고를 한 번에 (cs-harness)
---
지금 폴더(cs_practice)에서 아래 순서대로 한다. 순서를 바꾸거나 건너뛰지 않는다.

1. 시작 시각을 적어 둔다.
2. cs-reply 에이전트를 불러 문의.txt 15건 답변을 응대규정.md 대로 쓰게 한다 (업무 지시서대로 답변 폴더에 새 파일).
3. 에이전트를 하나 더 검산 담당으로 따로 불러, 답변 파일을 응대규정.md 와 문의마다 대조하게 한다. 규정 내용이 다른 문의 번호와 이유만 받는다 (말투 차이는 세지 않는다).
4. 다른 문의가 있으면 cs-reply 에게 전해 고친 답변 파일을 다시 만들게 하고, 3번을 한 번 더 한다. 두 번째에도 다르면 고치지 말고 그대로 보고한다.
5. 이 플러그인의 scripts/slack_report.js 를 지금 폴더에서 node 로 실행해 보고한다. 플러그인 폴더 위치를 모르면 찾아서 전체 경로로 실행한다.
   - 다 맞으면: --status ok --title "문의 답변" --check "15건 중 15건 규정 일치" --error "없음"
   - 남으면:  --status fail --title "문의 답변" --check "15건 중 N건 규정 일치" --error "문의 번호 · 이유"
   - --action 은 저장한 파일 이름, --elapsed 는 1번부터 걸린 시간
6. 마지막 답은 3줄: 검산 결과 · 답변 파일 이름 · 슬랙 보고 ok 여부. 학생 이름 · 학부모 정보는 보고에 넣지 않는다.
