# 직영 과목수 · 학생수 세는 법

## 공통 — 과목이 아닌 프로그램은 뺀다
프로그램명에 다음 말이 들어간 행은 빼고 센다.
셔틀, 차량, 주도, 클리, 유형별, 실험복, 가방, 클린업, 무료
(부분 일치로 뺀다 — 「주도」는 자기주도 · 자주도, 「클리」는 클리닉 · 클리커 연구소까지 빠진다. 직영 대시보드와 같은 기준. 「자기」만으로는 빼지 않는다)

## 과목수
아래 두 경우의 행만 센다.
- 학급수강상태가 「수강」
- 학급수강상태가 「이수」이고 이동 열이 「이동-」(반이동)이 아님

세는 단위(중복 제거):
- 요일 열이 「요일」(날짜로 잡는 특강)이면 COLC + 요일 + 시작시간 + 종료시간 — 같은 반이라도 시간대가 다르면 따로 센다
- 요일 열이 월~일이면 COLC + 요일 + 시작시간

## 학생수
과목수와 같은 행(수강 + 반이동 아닌 이수)을 **센터별로** 학생코드 중복 없이 센 뒤, 센터 값을 더한다.
전체에서 한 번에 세지 않는다 — 두 센터를 다니는 학생은 센터마다 한 명씩 센다.
신규생 · 재입회생 · 학년별 학생수도 같은 방식(센터별로 센 뒤 더하기)으로 센다.

## 세는 방법
- 파일이 크다. 통째로 읽지 말고 Node 명령(node -e 또는 .js 파일)으로 센다. Python 은 쓰지 않는다(1step PC 에 없다).
- 달을 말하지 않으면 편성년월별로 모두 보여 준다.
- 결과와 함께 「어떤 기준으로 셌는지」 한 줄을 붙인다.
