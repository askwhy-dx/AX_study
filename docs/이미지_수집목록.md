## 3. 촬영 규칙

- 새로 설치한 것 같은 기본 상태에서 찍는다. 다른 프로젝트·메모리·대화 기록이 보이지 않게 빈 연습 폴더(예: `C:\Users\<계정>\Desktop\claude_work`)를 쓴다.
- 창 크기를 모든 화면에서 같게 한다. 터미널 글자가 HTML에서 읽힐 만큼 크게 (확대 125% 이상).
- PNG로 저장, 마우스 커서 없이. 계정명·이메일·다른 환경 변수는 찍은 뒤 가린다.
- 촬영한 날짜와 `claude -v` 버전을 이 파일 아래에 적는다. 화면이 바뀌면 어느 이미지가 옛 버전인지 알 수 있게.
