## 끝난 일 (2026-09-22) — 설치 ZIP 점검 + `install.ps1` 보강

ZIP 안을 실제로 열어 점검했다. **`설치하기.bat` 은 이미 `-ExecutionPolicy Bypass` 를 붙이고 있어 실행 정책 함정에 안 걸린다**(ASCII·CRLF 도 지켜져 있었다).
그런데 다른 것 3건이 나와 고쳤다.
- **`[4/4]` 가 `irm | iex` 하나뿐이었고, 실패 안내가 「나중에 `irm ... | iex` 를 직접 실행하세요」 였다** — 인증서 신뢰 오류 PC 에서는 몇 번을 해도 같은 자리다.
  바로 앞 `[1/4]` 에서 Node.js 를 깔아 두고도 안 쓰고 있었다. **실패하면 `npm.cmd install -g --allow-scripts=... ` 로 한 번 더 시도**하게 했다.
- **설치 판정이 `.local\bin\claude.exe` 한 곳만 봤다.** npm 으로 깔리면 `%APPDATA%\npm` 이라 결과표에 「설치 안 됨」으로 뜨고 재실행 때마다 다시 깐다.
  `Test-ClaudeInstalled` = `(Test-Path $claudeExe) -or (Has claude)` 로 두 곳을 본다.
- **끝의 「다음에 할 일」이 v1.17 과 어긋났다** — `[File] > [Open Folder]` 영어 메뉴에 재시작 안내가 없었다.
  ZIP 이 한글팩까지 깔기 때문에 **다시 열면 한국어**다. `0. 완전히 종료했다가 다시 연다` 를 넣고 `[파일] > [폴더 열기]` 로, 각 줄에 가이드 단계 번호를 붙였다.
  `읽어보세요.txt` 도 같이 고쳤고 「잘 안 될 때」에 인증서 오류 문구와 대처를 넣었다.
- ⚠️ **작업한 곳은 `C:\Users\User\Downloads\입문과정설치파일\` 이다** (드라이브 ZIP 을 사용자가 받아 푼 것).
  옛 원본 폴더 `Desktop\입문과정설치파일\` 은 **이 PC 에 더는 없다.** 백업은 같은 폴더의 `*.260922.bak` 2개.
- **드라이브 반영 완료 (2026-09-22 15:45).** 크기 `267,734,802` 바이트가 로컬 새 ZIP 과 바이트까지 일치하는 것을 확인했다.
- ⚠️ **ZIP 을 다시 말 때 두 가지를 틀리기 쉽다.**
  ① **파일을 ZIP 루트에 넣는다** — 폴더를 통째로 「압축 폴더로 보내기」 하면 최상위에 `입문과정설치파일/` 이 한 겹 생겨,
  교육생이 풀면 `입문과정설치파일\입문과정설치파일\설치하기.bat` 이 된다(읽어보세요.txt 안내와 어긋난다).
  ② **`.bak` 은 빼고 넣는다.** 사용자가 15:41 에 만든 판이 둘 다 걸려 있어 다시 말았다(python `zipfile`, 루트 저장, 8초).

  **가이드·README 는 폴더 링크만 쓰므로 영향 없다**(guide 196·450줄, README 21줄. 파일 직링크는 어디에도 없다).
