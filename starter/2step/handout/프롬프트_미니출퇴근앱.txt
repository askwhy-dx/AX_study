[웹앱 코드 카드] PART 4 · 12단계. 11단계에서 구글 시트(sheets.new, 제목 「출퇴근 기록」)를 만든 뒤 붙여넣고 Enter
              (app_trial 안에 서버.gs 와 index.html 이 생긴다. 13단계에서 시트의 [확장 프로그램] > [Apps Script] 에
               서버.gs 는 코드 파일에, index.html 은 [+] > HTML 로 만든 파일 index 에 붙이고 [새 배포] > 웹 앱:
               실행 계정 = 나, 액세스 권한 = askwhy.co.kr 내 모든 사용자)
              5분 넘게 두 파일이 안 생기면 받은 정답_서버_웹앱.gs · 정답_index.html 을 app_trial 에 넣고 이름을 서버.gs · index.html 로

출퇴근 앱을 회사 계정으로 로그인해서 쓰는 웹앱으로 만들어 줘. 11단계에서 만든 구글 시트에 붙일 Apps Script 파일 두 개를 app_trial 에 만든다.
- 서버.gs: doGet 은 index.html 화면을 돌려준다(휴대폰 화면 폭에 맞게 viewport 를 넣는다). 기록 저장 함수와 내 기록 읽기 함수를 만든다
- index.html: 출퇴근.html 화면과 기능 그대로, Apps Script 편집기에 HTML 파일(이름 index)로 붙일 파일이다. 기록은 google.script.run 으로 서버.gs 함수를 불러 저장한다. 실패하면 "시트 저장 실패" 를 잠깐 보여 준다
- 누가 찍었는지는 서버가 Session.getActiveUser 로 로그인한 이메일을 읽어 정한다
- 기록은 이 스크립트가 붙은 시트의 첫 탭에 쓴다. 첫 줄이 비어 있으면 머리글을 쓰고 맨 오른쪽 칸은 이메일이다. 같은 날짜 + 같은 이메일 줄이 있으면 그 줄을 고친다
- 날짜 · 시각은 시트가 날짜 값으로 바꾸지 않게 글자 그대로 저장한다
- 화면을 열면 맨 위에 로그인한 이메일을 보여 주고, 표는 시트에 있는 내 기록으로 채운다
- 출퇴근.html 은 고치지 않는다. app_trial 의 CLAUDE.md 에 두 파일이 무엇인지 적어 줘
끝나면 두 파일을 시트의 Apps Script 편집기에 붙여 새 배포(웹 앱 · 실행 계정 나 · 액세스 askwhy.co.kr 내 모든 사용자)하는 방법을 세 줄로 알려 줘.
