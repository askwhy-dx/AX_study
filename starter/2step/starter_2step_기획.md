## 1. 핵심 결정 — 「교육자가 가장 쉬운 방식」을 어떻게 만들었나

### 결정 A. 완성본을 **따라 만들지 않는다** — 한 파일짜리 **미니 앱**을 만든다

완성본을 그대로 따라 만들려면 교육생마다 아래가 필요하다.

| 필요한 것 | 1step 현장에서 생기는 일 |
|---|---|
| GitHub 계정 + 토큰 | 계정 없는 사람 · 토큰 권한 오류 |
| Google Cloud OAuth 클라이언트 | 동의 화면 · 승인된 원본 · 리디렉션 URI 설정. 한 명만 틀려도 30분이 간다 |
| Apps Script 배포 | 「새 배포」와 「새 버전」 혼동 · 권한 승인 창 |
| 구글 시트 공유 설정 | 회사 데이터가 섞일 위험 |

**진행자 한 명이 10명의 계정 문제를 동시에 풀 수 없다.** 그래서 교육생이 만드는 것은
**`출퇴근.html` 한 파일**로 줄인다 — 로그인 없음 · 서버 없음 · 계정 없음 · 설치 추가 없음(starter 완료 전제).
기능은 완성본의 핵심 셋만 남긴다: **출근 버튼 → 회사 반경 판정 → 기록**.

| | 완성본(보기만) | 미니 앱(직접 만든다) |
|---|---|---|
| 화면 | GitHub Pages | 내 노트북의 HTML 파일 (더블클릭) |
| 로그인 | 구글 로그인 + 조직도 | 없음 |
| 기록 | 구글 시트 | 화면 표 + CSV 내려받기 |
| 알림 | 없음 (09:35 메일 2026-09-28 중지) | 없음 |

### 결정 B. 교육생이 치는 것은 **프롬프트 카드 복사 → 붙여넣기** 하나다

타자를 치게 하면 문장이 사람마다 달라지고, 결과가 달라지면 진행자가 10개의 서로 다른 화면을 봐야 한다.
**만들기 단계는 복사 버튼 하나짜리 카드**로 고정한다. 말로 고치는 단계(결정 D)에서만 자기 말로 친다.

### 결정 C. 막힌 사람은 **정답 파일로 갈아탄다** — 진행자가 고쳐 주지 않는다

`handout/정답_출퇴근.html` 을 미리 배포한다. 만들기에서 5분 안에 화면이 안 나오면 **그 파일을 작업 폴더에 넣고
다음 단계(고치기)로 간다.** 고치기 단계는 정답 파일로도 똑같이 2step된다. 진행자가 한 사람 화면에 붙잡히는 일이 없어진다.

### 결정 D. 2step의 본체는 「만들기」가 아니라 **「말로 고치기」**다

한 번 만들어지는 것은 구경이다. 2step은 **내 말로 고쳤더니 바뀌었다**에서 생긴다.
미션 카드 2장을 주고 **정답 문장을 주지 않는다** — 「무엇을 원하는지」만 적혀 있다.

| 미션 | 카드에 적힌 것 (원하는 결과) | 통과 화면 |
|---|---|---|
| 1 | 회사 반경을 100m 에서 **300m** 로 넓히고 싶다 | 화면 설정 줄에 `300m` |
| 2 | 퇴근을 누르면 그날 **일한 시간**이 표에 보이면 좋겠다 | [퇴근] 뒤 표에 「몇 시간 몇 분」 |

### 결정 E. 판정은 「화면에 이게 보이면 통과」로 적는다 (basic 결정 D 와 같은 원칙)

LLM 결과는 매번 조금씩 다르다. 그래서 **정확한 화면이 아니라 통과 조건**을 적는다.
예: 「출근 버튼을 눌렀을 때 아래 표에 오늘 날짜 줄이 생기면 통과」.

### 결정 F. 위치가 안 잡혀도 멈추지 않는다 — **테스트 모드**를 프롬프트에 넣는다

노트북은 GPS 가 없어 와이파이로 위치를 잡는다. 윈도우 위치 서비스가 꺼져 있거나 브라우저가 권한을 막으면
**아무 일도 안 일어난 것처럼 보인다.** 프롬프트에 「**테스트 모드** 스위치를 켜면 회사 좌표에 있는 것으로 친다」를 넣어
위치 문제로 1step이 멈추지 않게 한다. 실제 위치 판정은 **완성본(휴대폰)** 에서 체험한다.

## 2. 진행 흐름 (45분 · 진행자 1명 · 교육생 10명 기준 · v1.6)

| 순서 | 시간 | 무엇 | 진행자가 하는 일 | 교육생 결과 |
|---|---|---|---|---|
| ① 보기 | 5분 | 완성본 앱을 휴대폰으로 찍어 본다 | 링크 QR 을 화면에 띄운다 | 기록 표에 내 출근 1줄 |
| ② 만들기 | 10분 | 프롬프트 카드 붙여넣기 → `출퇴근.html` 생성 → 더블클릭 | 「5분 지나면 정답 파일」만 외친다 | 내 노트북에서 출근 버튼이 동작 |
| ③ 말로 고치기 | 10분 | 미션 카드 1 → 2 → (3) | 먼저 끝난 사람 화면을 한 번 띄워 준다 | 미션 2개 이상 통과 |
| ④ 시트를 DB 로 | 15분 | 11 시트 만들기 · 12 서버 코드 카드 · 13 Apps Script 웹앱 배포 · 14 연결 카드 | 13단계 배포 화면을 진행자 화면으로 한 번 같이 누른다 | 시트에 내 출근 · 퇴근 1줄 |

**진행자 준비는 3가지뿐이다** — ① 교육생 구글 계정을 조직도 탭에 등록(완성본 2step용) ② handout 폴더 공유 ③ 가이드 링크 공유.

| PART | 제목 | 단계 | 누가 읽나 |

| 2 | 미니 앱 만들기 | 4 작업 폴더에서 Claude Code 켜기(starter 작업 폴더 그대로 · 카드가 `app_trial` 을 만든다) · 5 프롬프트 카드 붙여넣기 · 6 파일 열어 보기 · 7 테스트 모드로 출근 찍기 | 교육생 |
| 3 | 말로 고치기 | 8 미션 1 반경 · 9 미션 2 일한 시간 · 10 폰 화면으로 보기 | 교육생 |
| 4 | 구글 시트를 DB 로 (v1.6) | 11 시트 만들기 · 12 서버 코드 카드(`서버.gs`) · 13 시트에 붙이고 웹앱 배포(나 · 모든 사용자) · 14 앱과 시트 연결 카드 | 교육생 |
| 5 | 막혔을 때 (앵커는 `#p6` 그대로) | 증상 → 원인 → 해결 표 + 「정답 파일로 갈아타기」 · 시트/웹앱 5줄(v1.6) | 교육생·진행자 |
| 부록 | **진행자용** | 30분 시간표 · 말할 문장(대본) · 준비물 체크리스트 · 자주 막히는 곳 TOP 3 | 진행자 |

- 단계 카드마다 **「확인 — 화면에 이게 보이면 통과」** 한 줄과 캡처 1장.
- **진행자 부록**이 starter 가이드와 다른 점이다. 진행자가 가이드 하나만 열고 위에서 아래로 읽으면 진행이 끝나게 만든다.
- PART 1 은 완성본 URL 만 싣는다. **시트 주소 · 조직도 · 백엔드 URL · 이메일은 가이드에 싣지 않는다**(공개 링크).

```
지금 작업 폴더 안에 app_trial 폴더를 만들고, 그 안에 출퇴근.html 파일 하나를 만들어 줘. 다른 설치는 필요 없게.

- 100m 안이면 기록, 밖이면 "반경 밖" 안내

- 맨 위 한 줄에 지금 설정(반경, 기준 시각 09:30)을 보여 줘
- 같은 app_trial 폴더에 CLAUDE.md 도 만들어 줘: 이 앱이 무엇인지, 지금 설정(회사 좌표 · 반경 · 기준 시각), 기록이 어디에 저장되는지를 짧게 적고, 출퇴근.html 을 고치면 CLAUDE.md 의 설정도 같이 고치라고 적어 줘. 작업 폴더에 원래 있던 CLAUDE.md 는 건드리지 않는다
끝나면 파일을 여는 방법을 한 줄로 알려 줘.
```
