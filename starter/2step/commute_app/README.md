## 홈 화면 아이콘

브라우저 기능이라 설치 파일이 없다. 아이콘은 `index.html` 에 data URI로 인라인돼 있다.

| OS | 방법 |
|---|---|
| iOS Safari | 하단 공유 버튼 > 홈 화면에 추가 |
| Android Chrome | 우측 상단 점 3개 > 홈 화면에 추가 |

**로그인 경로가 실행 방식에 따라 갈린다.**

| 실행 방식 | 로그인 |
|---|---|
| 브라우저 탭 (Chrome, 카카오톡 인앱 등) | GIS 팝업 버튼 |
| 홈 화면 아이콘 (standalone) | 같은 탭 리다이렉트 (`response_type=id_token`) |

iOS 홈 화면 웹앱은 **팝업을 띄울 수 없고** Safari 와 저장 공간도 분리돼 있어서, 팝업 방식 로그인은 `accounts.google.com` 백지로 끝난다. `navigator.standalone` / `display-mode: standalone` 으로 갈라서 리다이렉트를 쓴다. 리다이렉트 URI가 콘솔에 등록돼 있어야 한다(2단계 4항).

- `전체권한` 이 `Y` 면 전 직원 기록을 본다. 비었거나 열이 없으면 N 으로 본다. 한 사람은 주소 하나만 쓴다(두 주소로 번갈아 찍으면 기록이 둘로 갈린다)
- 열은 헤더 이름으로 찾는다. 헤더 글자가 틀리면 알림·접속이 에러로 멈춘다(조용히 0명이 되는 것보다 낫다)
- 대소문자와 앞뒤 공백은 코드가 흡수한다. 팀이 비었거나 이메일 형식이 아닌 행은 조용히 버려진다
- 퇴사자는 행을 지우면 즉시 접속·판정 대상에서 빠진다(요청마다 조직도를 다시 읽는다). 과거 기록은 `기록` 탭에 남는다

## 함정

- ~~Apps Script 웹앱 화면에 GPS를 두면 안 된다~~ **2026-09-27 실측으로 뒤집혔다.** 지금 HtmlService iframe 에는 `allow="geolocation *"` 이 있고 사내 웹앱(`dashboard_webapp`)에서 위치를 실제로 받았다. 화면이 GitHub 에 따로 있는 것은 제작 당시(09-22) 제약 때문이고, 2step 15단계는 화면을 웹앱에 둔다.
- **일일 시각 트리거는 지정 시각부터 1시간 안 임의 시점에 발화한다.** 09:35 판정에는 못 쓴다. 5분 간격 트리거 + `ScriptProperties` 1일 1회 가드로 우회했다.
- **요청 Content-Type은 `text/plain` 이어야 한다.** `application/json` 이면 preflight OPTIONS가 발생하고 Apps Script는 OPTIONS를 처리하지 못한다.
- **거리 판정을 클라이언트만 믿으면 안 된다.** 서버가 같은 식으로 다시 계산한다. 화면 값은 표시용이다.
- **실내 GPS는 수십 m 튄다.** 오차 관용식이 이걸 흡수한다. 반경을 50m로 줄이면 자기 자리에서도 거부된다.
- **`GITHUB_REPO=tes1` 은 쓰지 않는다.** `upload.js` 는 `tes2` 를 하드코딩한다. 사내 발행기가 공개 리포로 새지 않게 `.env` 값을 일부러 안 고친 상태다.
- **ID 토큰은 1시간 만료다.** 만료되면 "로그인이 만료되었습니다" 와 함께 로그인 화면으로 돌아간다. 정상 동작이다.
- **OAuth 브랜딩에 로고를 넣지 않는다.** 넣으면 인증 제출 대상이 된다.
- **시트 공유를 도메인 전체로 열지 않는다.** 누구나 기록과 조직도를 고칠 수 있게 된다.
