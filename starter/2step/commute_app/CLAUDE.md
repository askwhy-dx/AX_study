백엔드  Apps Script /exec / code.gs    토큰 검증, 거리 재검증, 시트 기록, 메일
  |

명부    시트 [조직도]                    팀/이름/직책/이메일/전체권한. 관리자 수기. 접속 명단 + 알림 + 판정 모집단 + 열람 범위

**화면과 백엔드가 왜 갈라져 있나.** Apps Script `HtmlService` 는 페이지를 크로스오리진 iframe 에 넣는데 그 sandbox 에 `allow="geolocation"` 이 없다. `navigator.geolocation` 이 **에러도 없이** 거부된다. 출퇴근 앱을 Apps Script 화면 하나로 합치려는 시도는 반드시 실패한다. → **2026-09-27 실측으로 뒤집혔다**: 지금은 `sandboxFrame` 에 `allow="geolocation *"` 이 있고, 사내 웹앱에 시험 페이지를 올려 크롬에서 좌표를 실제로 받았다(시험 페이지는 휴지통). 2step 15단계가 이 구조(화면도 웹앱 · 액세스 도메인)다. 완성본을 옮길지는 따로 판단한다.

## 건드리면 깨지는 곳

- **좌표와 반경이 두 파일에 중복이다.** `code.gs` `CFG.OFFICE_LAT/LNG`·`RADIUS_M` 과 `index.html` `OFFICE`·`RADIUS_M`. 한쪽만 고치면 **화면은 통과하는데 서버가 거부**한다. 설정 배포 엔드포인트가 정석이지만 값이 거의 안 바뀌어 중복을 택했다.
- **시간을 시트에 그냥 쓰면 안 된다.** 시트가 `'09:12'` 를 시간 값(Date)으로 자동 변환한다. 화면에 `1899-12-30T..Z` 가 뜨고, 더 나쁘게 `judge_` 의 문자열 비교가 **정시 출근도 지각으로** 기운다. `setTime_()`(텍스트 서식 고정)으로 쓰고 `timeStr_()` 로 읽는다. 이 두 함수를 우회하지 말 것.
- **일일 시각 트리거는 지정 시각부터 1시간 안 임의 시점에 발화한다.** 09:35 판정에 못 쓴다. 5분 간격 + `ScriptProperties.lateSent` 1일 1회 가드로 우회했다.
- **`checkLate_` 는 대상이 0명이면 플래그를 찍지 않는다.** 이 가드가 없으면 명부가 비어 있던 회차가 그날 발송권을 태워서, 뒤늦게 등록한 사람이 판정에서 통째로 빠진다. 실제로 2026-09-22 에 겪었다.
- **요청 Content-Type 은 `text/plain` 이어야 한다.** `application/json` 이면 preflight OPTIONS 가 생기고 Apps Script 는 OPTIONS 를 처리하지 못한다.
- **거리 판정을 클라이언트만 믿으면 안 된다.** 서버가 같은 식으로 다시 계산한다. 화면 값은 표시용이다.
- **정확도(acc) 상한 `MAX_ACC_M` 을 빼지 말 것.** acc 는 거리에서 빼는 값이라 `acc=99999` 나 `NaN` 을 보내면 어디서든 출근이 찍혔다(09-23 점검에서 발견). 좌표 위조 자체는 웹으로 못 막는다.
- **로그인 경로가 실행 방식에 따라 갈린다.** iOS 홈 화면 웹앱은 팝업을 띄울 수 없고 Safari 와 저장 공간도 분리돼 있어서 GIS 팝업이 `accounts.google.com` 백지로 끝난다. `navigator.standalone` / `display-mode: standalone` 이면 같은 탭 리다이렉트(`response_type=id_token`)를 쓴다. **콘솔에 리디렉션 URI 가 등록돼 있어야** 동작한다.
- **`GITHUB_REPO=tes1` 은 쓰지 않는다.** `upload.js` 가 `tes2` 를 하드코딩한다. 사내 발행기가 공개 리포로 새지 않게 `.env` 값을 일부러 안 고친 상태다. `test/` 에서 `git init` 금지.
- **OAuth 브랜딩에 앱 로고를 올리지 말 것.** 외부 + 프로덕션에서 로고가 있으면 "앱을 인증해야 합니다" 배너가 뜨고 인증 제출 대상이 된다(09-23 실제로 겪음, "창탐" 로고 삭제로 해소). 기본 범위(`openid email profile`)만 쓰면 로고 없이 인증 없이 동작한다. 브랜딩은 프로젝트 `freetest-envet` 의 **모든 클라이언트가 공유**한다.
- **구글 로그인 문은 열려 있고 실제 문지기는 조직도다.** 외부 + 프로덕션이라 모든 구글 계정이 구글 로그인은 통과한다. `verifyToken_` 이 **요청마다** 조직도를 다시 읽어 거른다. 이 검사를 캐시하거나 `init` 에서만 하면 조직도에서 지운 사람이 계속 찍을 수 있다.
- **시트 공유를 도메인 전체로 되돌리지 말 것.** 백엔드는 소유자 권한으로 돌아서 공유가 필요 없다. 공유가 열리면 누구나 `기록` 을 고치고 `조직도` 에서 자기 행을 지워 알림을 피할 수 있어, 앱의 전체권한 구분이 무의미해진다.
- **차단 시 `disableAutoSelect()` 를 빼지 말 것.** GIS `auto_select: true` 라 계정이 하나뿐인 브라우저에서 조직도 밖 계정은 로그인 → 차단 → 자동 로그인이 무한 반복된다. `index.html` `boot()` 가 권한 오류일 때만 끄고 사유를 `#loginErr` 에 보여준다(만료 오류는 자동 로그인 유지).
- **아이콘 PNG 는 HTML 안에 data URI 로 인라인돼 있다.** GitHub 이미지 업로드 금지 규칙 때문이다. 파일로 빼려면 유저 확인부터.

## 보안 점검 (2026-09-23)

로그인한 사용자가 할 수 있는 부정행위를 점검했다.

| 방법 | 결과 | 조치 |
|---|---|---|
| 요청의 `acc` 를 `99999`·`NaN` 으로 보내기 | **어디서든 출근됐다** | `MAX_ACC_M=100` 초과·비숫자 거부 |
| 시트 직접 수정 | 도메인 전체 편집자라 **누구나 가능했다** | 유저가 공유를 제한됨으로 변경 |
| 개발자도구 센서·가짜 GPS 앱으로 좌표 위조 | 가능 | 웹으로 못 막는다. 네이티브·Wi-Fi·비콘 필요 |
| 타인 명의 출근 | 불가 | 구글 ID 토큰 서버 검증 (`aud`·`email_verified`) |
| 기기 시계 조작 | 불가 | 시각은 서버 시계 |
| 출근 재기록으로 시각 덮어쓰기 | 불가 | 출근 첫 기록 유지 |

**소스 공개.** `tes2` 는 공개 리포라 `commute/index.html` 은 누구나 볼 수 있다. 브라우저가 내려받는 코드라 리포를 비공개로 해도 못 숨기고, 무료 계정은 비공개 리포로 Pages 를 못 돌려 앱이 죽는다. 그대로 둔다. 화면에 있는 것은 `/exec` 주소·클라이언트 ID(공개용)·사무실 좌표·요청 형식뿐이고 **비밀값·시트 ID·명단·기록은 없다.** `code.gs` 는 GitHub 에 올리지 않는다.

## 안 만든 것

근무시간 집계, 관리자 화면, 휴가·반차, 퇴근 미처리 알림, GPS 위조 차단, 오프라인 큐, PWA manifest.

**자정을 넘겨 퇴근하는 경우**는 미처리다. 어제 09:20 출근 후 오늘 00:30 에 퇴근을 누르면 어제 행의 퇴근이 비고 오늘 행에 퇴근만 남는다. 야근이 흔해지면 "오늘 출근 기록이 없고 어제 행 퇴근이 비었으면 어제 행에 기록" 규칙으로 막는다.

**GPS 위조는 웹으로 막을 수 없다.** 필요해지면 네이티브 전환 건으로 따로 봐야 한다.
