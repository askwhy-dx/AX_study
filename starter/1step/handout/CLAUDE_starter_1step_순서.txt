Claude Code 첫 설정 1step 순서
=============================

이 문서는 설치가 끝난 뒤(HTML 가이드 1~8단계) 할 일을 적은 요약본이다.
HTML 가이드는 (1)설치 1~8단계 (2)세팅 9~11단계 (3)팁 (4)막혔을 때 네 묶음으로 나뉘어 있고,
아래 0~2번은 그 중 (2)세팅에 해당한다. 네 묶음 모두 접힌 채로 열리므로 필요한 묶음의
제목을 눌러 편다. 막히면 가이드 맨 위 [막혔을 때] 를 누른다.

준비물
------
- Claude 유료 계정(Pro 이상) : Claude Code 는 무료 계정으로는 쓸 수 없다
- 설치파일.zip        : Node.js · VS Code 설치 파일 (구글 드라이브)
                        압축을 폴더로 푼 뒤 안의 VS Code · Node.js 설치 파일을 하나씩 실행한다.
                        ZIP 안에서 바로 더블클릭하지 않는다.
                        확장 3종(3단계) · Claude Code(7단계)는 가이드대로 직접 설치한다.
- CLAUDE_초기설정.txt : 작업 폴더 규칙(CLAUDE.md)을 만든다


0. 작업 폴더 만들기
-------------------
1) 바탕화면 또는 업무 폴더에 작업 폴더를 하나 만든다.
   - 폴더 이름은 영어로, 공백 없이 짓는다. (예: claude_work)
   - 한글이나 공백이 있으면 1번에서 규칙 파일이 만들어지지 않고 멈춘다.
2) 그 작업 폴더에서 Claude Code 를 실행한다.
   - 바탕화면 자체나 사용자 폴더(C:\Users\<계정>)에서 실행하면 안 된다.
   - 처음 실행하면 폴더 신뢰 창이 뜬다. 기본 선택이 "No, exit" 라 Enter 만 누르면 꺼진다.
     아래 화살표로 "Yes, I trust this folder" 를 고른 뒤 Enter.
3) 답변 언어를 한국어로 설정한다. (처음 한 번만)
   - /config 입력 > Language 항목 선택 > korean 입력 > /exit > claude 다시 실행
   - 메뉴와 화면 글자는 영어 그대로이고, Claude 의 답변만 한국어로 바뀐다.
   - 모든 폴더에 적용된다.


1. 규칙 만들기 (CLAUDE_초기설정.txt)
------------------------------------
1) CLAUDE_초기설정.txt 를 메모장으로 연다.
2) Ctrl+A (전체 선택) > Ctrl+C (복사)
3) Claude Code 입력창에 Ctrl+V (붙여넣기) 하고 Enter.
4) 파일을 만들어도 되는지 물어보면 허용한다. (기본 auto 모드에서는 묻지 않고 바로 만든다)
5) 붙여넣기는 이 한 번뿐이고, 끝나면 아래 파일이 생긴다. (이 작업 폴더에만 적용 / 폴더 규칙, 프로젝트 목록)
      <작업 폴더>\.claude\CLAUDE.md


2. 적용 확인
------------
1) Claude Code 를 완전히 껐다가, 작업 폴더에서 다시 실행한다.
   (CLAUDE.md 는 다시 실행해야 적용된다)
2) "이 작업 폴더의 규칙을 요약해줘" 라고 물어본다.
   -> 「프로젝트는 영어 이름 폴더로 만든다」 같은 폴더 구조 규칙과 프로젝트 개요를 말하면 정상


알아둘 점
---------
- CLAUDE.md 는 Claude Code 를 켤 때마다 항상 읽힌다. (매번 지킬 규칙)

- 작업 폴더 CLAUDE.md
  | 파일                          | 적용 범위                                   | 내용                         |
  | <작업 폴더>\.claude           | 그 작업 폴더(하위 폴더 포함)에서 실행할 때  | 폴더 구조, 프로젝트 목록     |
  답변 언어(한국어)는 CLAUDE.md 가 아니라 /config 언어 설정이 담당한다. (0번 3)

- 업무가 늘어나면 새 작업 폴더를 만들지 말고, 작업 폴더 안에 하위 폴더를 만든다.
  | 구조                                   | 작업 폴더 CLAUDE.md                            |
  | <작업 폴더>\업무A, <작업 폴더>\업무B    | 1개만 만들면 된다 (하위 폴더에서 실행해도 읽힘) |
  | 바탕화면\work, 바탕화면\study (여러 개) | 폴더마다 따로 만들어야 하고, 고칠 때도 폴더마다 |

되돌리기
--------
- 작업 폴더 규칙 : <작업 폴더>\.claude\CLAUDE.md 삭제
- 답변 언어   : /config > Language 항목에서 korean 을 english 로 바꾼다.
  (.claude 폴더 전체를 지우면 안 된다. 다른 설정도 들어 있다)
- 지운 뒤 Claude Code 를 다시 실행한다.
