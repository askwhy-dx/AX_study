아래 [작업 폴더 규칙] 으로 이 작업 폴더의 규칙 파일을 만들어줘. 설명과 파일 내용은 한국어로 쓴다.

1. 작업 폴더 = 지금 Claude Code 를 실행한 현재 폴더다. 전체 경로와 폴더 이름을 먼저 확인한다.
   폴더 이름에 한글이나 공백이 있거나, 바탕화면 자체·사용자 폴더(C:\Users\<계정>)이면
   아무것도 만들지 말고 멈춘 뒤 이유를 알려준다.
2. 파일은 <작업 폴더>\.claude\CLAUDE.md 에 만든다. .claude 폴더가 없으면 만든다.
   작업 폴더 바로 아래, 사용자 폴더의 .claude 에는 만들지 않는다. /init 은 쓰지 않는다.
3. CLAUDE.md 가 이미 있으면 CLAUDE.md.bak 으로 백업하고, 기존 내용은 지우지 말고 아래 내용을 합친다.
4. <작업 폴더명> 은 1번에서 확인한 실제 폴더 이름으로 바꾼다.
5. "프로젝트 개요": 작업 폴더 안에 프로젝트 폴더가 있으면 이름과 한 줄 설명만 목록으로 적고,
   없으면 "아직 프로젝트 없음" 한 줄만 적는다. 없는 내용을 지어내지 않는다.
6. UTF-8 로 저장하고 이름이 CLAUDE.md 인지 확인한다. (CLAUDE.md.txt 가 되면 안 됨)
7. 끝나면 아래만 짧게 알려준다.
   - 파일 경로, 새로 만들었는지 / 합쳤는지 / 멈췄는지 (멈췄으면 이유)
   - 적용하려면 Claude Code 를 작업 폴더에서 다시 실행해야 한다는 안내

# <작업 폴더명> 작업 공간

## 규칙
- 커밋 메시지와 문서(README.md 등)는 한국어로 쓴다.
- 프로젝트는 <작업 폴더명>\프로젝트명\ 폴더로 만들고, 폴더 이름은 영어로 짓는다.
- .claude 폴더에는 설정(CLAUDE.md, skills, settings)만 두고 프로젝트 파일은 넣지 않는다.
- 매번 지킬 규칙은 CLAUDE.md 에, 특정 요청에만 필요한 절차는 스킬에 둔다.
- 여러 프로젝트가 같이 쓰는 스킬은 <작업 폴더명>\.claude\skills\, 한 프로젝트만 쓰는 스킬은 <작업 폴더명>\프로젝트명\.claude\skills\ 에 둔다.
- 프로젝트 설명과 실행 절차는 그 프로젝트 폴더에서 /init 으로 만든 CLAUDE.md 에 둔다.
- 새 프로젝트를 만들면 아래 "프로젝트 개요"에 이름과 한 줄 설명을 추가한다.
